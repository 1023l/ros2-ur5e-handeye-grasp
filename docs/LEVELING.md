# 级别判断与资深口径（诚实版）

## 一句话结论

**现在够「扎实的中高级 / 强中级」作品集，还不够大厂口头的「高级 / 资深」默认线。**  
但赛道（具身 / 工业臂）人还不多，**用正确叙事 + 再补 2～3 块「决策型」深度，25k 上海臂岗是够抢的**；资深要的是「别人调库、你定方案并能量化」。

## 初级 / 中级 / 高级怎么分（结合你说的）

| 级别 | 典型行为 | 你朋友 Pink 八轴 | 你现在 |
|------|----------|------------------|--------|
| 初级 | 调库跑通 demo | — | 早期 MoveIt 抓放 | 
| 中级 | **适配 / 改造 / 集成** | ✅ 八轴 Pink 适配 | ✅ ROS2 产线拼装、难场景、评测 |
| 高级 | **定指标、做消融、选方法、设门控、能讲清失败** | 若还有对比与上线标准才算 | 🔶 已有一半：stress / bake-off / gate |
| 资深 | **定架构与边界、带人、扛线上事故、抽象可复用子系统** | 少见 | ❌ 还缺真实产线背书与更大 ownership |

朋友「适配 Pink 八轴」= 标准好中级：运动学/接口适配，面试能讲。  
你比纯调库强在：**工业手眼残差语言（visionguide/Ceres）+ 指标闭环 + 加压找悬崖 + 门控**——这是往高级挪的正确方向。

## 面试官听什么才像高级

1. **不是**「我用了 MoveIt / YOLO」  
2. **而是**「噪声下 Park 初值 + SE3-BA 均值最优；一致性精炼加门控防止过拟合；高遮挡用竖直 CLOSE+矩中心把 p90 从 30px 打到 8px；抓取按风险调整效用排序」  
3. 能量化：**消融、bake-off、悬崖点、失败模式分布**

## 简历怎么写（建议）

> 基于 ROS2 Humble + MoveIt2 搭建眼在手外仿真抓取产线：对齐工业 Ceres 手眼残差族，完成 OpenCV 多方法 vs SE3-BA vs 一致性门控的 bake-off；难场景视觉在遮挡加压下将像素误差 p90 压到个位数；抓取侧用不确定性风险调整排序；以可复现班次指标做闭环。
